# 同梱フォント

候補はすべて日本語・英語対応です。OSのフォントへ置き換えず、同じファイルを埋め込み／別窓プレビューとMP4のcanvas描画で使用します。古いプロジェクトの既定値はNoto Sans JPです。絵文字やすべての特殊文字への対応を保証するものではありません。

|---|---|---|

|Noto Serif JP · 明朝|NotoSerifJP.ttf（可変）|Google 2012、フォント内表記 Adobe 2017–2024、[NotoSerifJP-OFL.txt](NotoSerifJP-OFL.txt)|
|Zen Maru Gothic · 丸ゴシック|ZenMaruGothic-Medium.ttf / ZenMaruGothic-Bold.ttf（500 / 700）|The Zen Maru Gothic Project Authors 2021、[ZenMaruGothic-OFL.txt](ZenMaruGothic-OFL.txt)|
