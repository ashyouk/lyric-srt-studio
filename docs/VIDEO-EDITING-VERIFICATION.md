# 試作0.2：フォントと修正操作の検証

2026-10-01。Windows 10、Node 22.17.1、Python 3.13.2、FFmpeg 8.1.2、PC Edge headless。基準は `agent/lyric-video-prototype` の `59f4eab57cae57e9395f7ab614969903d11c35ab`。開始時に未コミット変更なし、originと一致。公開mainおよびルートの手動SRT版は変更していません。サブエージェントは使用していません。

## 実装

- 制作タブ：素材・入力歌詞・見た目・埋め込みプレビュー・保存／書き出し
- タイミング修正タブ：すべて／既存の要確認フラグによる絞り込み、選択行・現在の歌詞行を別表示、再生／停止・シーク、試聴、固定記録操作、Undo／Redo
- タブはDOMの表示切替だけ。プレーヤー・入力欄・解析結果・履歴を作り直しません。切替／スタイル／タイミング修正で解析APIを呼ばないことを監視して確認
- 行全体を±0.1秒移動。表示時間と自動推定の記録を保持し、両端を手動修正扱い・要確認にする。負の開始、曲外、無効区間を拒否。1操作＝1Undo。既存の端だけの調整と現在位置記録は維持
- 行番号で0.5秒手前へシーク。「この行を聴く」でその位置から再生。調整中の再生位置は戻さない。入力欄のフォーカスでも対象行を表示するが、シークしない
- 品質チェックは既存 `LyricSrtCore.analyzeProject` を再利用し、前後の重なりや無効時刻を表示。新しい同期精度・信頼度は作っていません
- 別窓にはcanvasだけを置き、音声／動画プレーヤーは置かない。同一オリジンの親画面からプロジェクト・再生時刻と元映像フレームを読み、共通描画を行う。子窓の再生操作も親へ渡す。独立した再生時計を持たない
- 初期状態、停止中の変更、歌詞、フォント、Undo／Redoを次の描画へ反映。1つの親につき1窓、再クリックはフォーカス、閉じる／戻す／親を閉じるで接続と確認タイマーを終了。ブロック時は操作欄にエラーを表示し、埋め込みは残す
- 修正タブは追従するコンパクトプレビュー。900px以下で時刻入力中は映像を畳んで追従を解除。44px操作領域・touch-action・ピンチズームを禁止しないviewportを維持。HTTP LANでrandomUUIDがない場合も起動する
- Noto Sans JP／Noto Serif JP／Zen Maru Gothic。日本語・英語対応、実字形の選択サンプル、同梱ファイルをすべての描画で使用。フォント読込を待ち、字幅・改行・複数行高さ・時刻からのスクロールを再計算。保存JSONは従来version 1を維持し、追加style.fontIdだけを保存。古い／未知の指定はNoto Sans JPへ。[ファイル・著作権・OFL](../video/fonts/README.md)

## 目視・未確認・制限

PCブラウザで生成したデスクトップ／390px画面の画像を目視し、修正欄・対象行と再生行の区別・コンパクト映像・固定ボタンを確認しました。実機のiPhone／iPad、Safari、Firefox、手操作でのピンチやソフトキーボードは未確認です。PC幅検査やフォーカス検査は実機確認の代わりではありません。

- ブラウザによって別窓が別タブになる、ポップアップ制限で開けない場合あり。モバイルは埋め込み／コンパクト表示を推奨
- 親画面を開いておく必要あり。バックグラウンドタブの描画はブラウザに間引かれる場合あり。再び表示すると親の現在時刻から描画するため、別時計の累積ズレは発生しない
- 絵文字・すべての特殊字形は保証しない。初回は追加フォント約21MBをPCから読む。フォント取得失敗を通知し、MP4描画は読込完了を待つ
- 保存JSONに素材本体・実行中の素材IDは含めない。再読込時には素材を再選択。タブ切替では不要
- 同期精度と従来の入力／書き出し範囲の制限は変更なし。販売完成版や全曲対応の保証ではない
