# 端末内SRT編集 β 0.3.1 — 検証と公開範囲

## 端末内自動同期 実験0.4.0（2026-10-21）

通常編集版とは別の `video/auto.html` から入ります。音声API・PC解析サーバーは使いません。同梱Transformers.js 3.8.1 / ONNX Runtime Webで、量子化した多言語Whisper tiny_timestampedをWASM単一スレッドで実行します。モデルの固定リビジョンは `video/browser-alignment.js`。通常編集モードはモデルも解析ランタイムも読み込みません。

音響の単語時刻を、正規化した照合文字へ対応させます。連続した長い一致をアンカーにし、その前後を順序を維持して照合します。単純なLCSは短い認識内容を後半の似た文字へ散らす問題があったため採用を取りやめ、回帰テストを追加しました。入力の表示本文・空行・構成タグ・繰り返しは保持。対応が60%未満の行、無効時刻、短すぎる部分対応は未配置とします。これは時刻の正解率／信頼度を意味しません。全行が要確認で、前奏・間奏・繰り返しの位置を自動保証しません。

### 実音源の結果と未達成

- 英語CC0アカペラ Twinkle 27秒：4行の音響時刻候補を生成。初回モデル取得込みで約15〜17秒（このPCのChromium、スマホ測定ではない）。1行に認識誤りによる部分境界の注意あり。人手の時刻採点は未実施。
- 提供済み「イエローテープ」114.48秒・29行：tiny初回追試は約75秒、十分な対応を得た行は0。無理に時刻を埋めず未配置とした。これは同期成功ではない。
- 同曲冒頭30秒の追加比較：baseは26.82秒で認識漏れ・誤認識が大きく、採用可能な行0。smallは73.04秒で認識が音楽記号のみ、採用可能な行0。モデル取得込み。これらは日本語歌唱へ一般化できる精度評価ではなく、この曲での失敗記録。base／smallはプローブ用で、画面から選択させない。
- 日英混在の合成読み上げ11.83秒：4行の原文・反復を保持し、4行に候補、キャッシュ利用時5.76秒。歌唱の成功例とは扱わない。固定した実行ライブラリは言語自動判定を実装していないため、表示を「自動判定」とせず、日本語／English／日英混在（日本語中心）から明示選択する。
- 日本語実曲を「全自動で完成できる」という条件は未達成。ブラウザ内で処理が動くことと、歌唱への実用精度は区別する。次段階は認識方式・歌声と伴奏への対処の検証が必要で、課金や音源の外部送信へは無断で切り替えない。

### 保存・安全性

解析結果は既存の `applyAlignment` / Undo / Redoへ接続。片端でも手動修正した行は再解析で時刻・確認状態を保護する。候補再生成前に確認を表示。開始時の歌詞・素材と完了時が異なる場合は古い結果を適用しない。中止はWorkerを終了し、途中の結果を適用しない。再実行可能。モデル名・リビジョン・処理方式・解析範囲をJSONに保存するが、素材本体・一時URLは含めない。SRTは引き続き確認済み行のみ。

モデル取得は利用者の同意後のみ。Workerのfetchを同一オリジンと固定モデル配布パスのGET/HEADだけに限定し、実処理テストでもAPI/POST/他サービスへの送信を遮断して検証する。Hugging Faceはダウンロード時のIP等を受け取るが、音源・歌詞は送信しない。音源・歌詞・結果はGitへ含めず、`.studio-data/verification/browser-sync/` 内だけで検証する。

Transformers.jsはApache-2.0、ONNX RuntimeはMIT（付属第三者通知を同梱）、元Whisperコード・重みはMIT。ONNX変換リポジトリの別途明示ライセンス欄はないため、販売配布前に重みの通知・ライセンスの連鎖を確認する必要がある。実験成功を商用ライセンス確認済みとしない。詳細は同梱 `NOTICE.md`。

実機Safari／Android、長時間の連続処理、画面ロック復帰、端末のメモリ上限は未確認。ブラウザ幅の確認はこれらの代わりにならない。試作は5分・100MB以内の音源のみ、まず30秒。音源の再生形式はブラウザに依存し、MP4出力は今回追加していない。

## 実曲と検証用時刻の区別

提供済み実曲の既存JSON（29行）とWAVを端末内モードで開き、本文・繰り返し・推定時刻・音響根拠が保持されることを確認しました。音源とJSONは `.studio-data/` 内にあり、Gitにも公開ページにも含めません。

短いWAVでの編集操作テストには、UI検証用に指定した時刻を使います。自動同期の結果や同期精度としては扱いません。実曲の新しい解析や人手による精度採点は今回行っていません。テスト中の確認済みフラグは機能検証用で、利用者の楽曲を聴いて承認したことを意味しません。

## 制限・実機で確認が必要なこと

- iPhone/iPad実機Safariの操作、ファイルピッカー、長時間再生、ファイル保存先、画面ロック後の復帰は未確認です。画面幅の自動確認で代替したとは扱いません。
- この画面では自動同期・MP4出力は行いません。PC版で同期したJSONを持ち込むか、手動で開始・終了を指定します。
- JSONに素材は含みません。再読込・別端末では同じ素材を再選択してください。履歴は現在の作業中だけで、JSON読込時はクリアします。
- 素材形式はブラウザのデコーダーに依存します。WAVの実再生は今回確認済み。MP3/M4A/MP4の各実機の可否は要確認です。動画の音声有無は端末内モードでは自動判定しません。
- フォントの初期読み込みには通信が必要です。完全オフライン配布・PWA・端末間の自動共有・クラウド保存は未実装です。
- SRTは有効な確定時刻と本文だけを持ち、書体・色・スクロールの見た目は含みません。表示設定はプロジェクトJSONへ保存します。
- ブラウザ自動保存とPC版の自動保存はキーを分離しています。ブラウザ保存が消える場合に備え、JSONファイルも保存してください。
